JustScan helps teams scan container images and Helm charts, investigate findings, and apply organization policy before software ships. This portal documents the current JustScan release running in your environment. Use the [release image reference](/reference/release-images) when planning an upgrade.

## Recommended rollout

1. Deploy with [Docker Compose](/deploy/docker-compose) or [Helm](/deploy/helm), then verify `/api/v1/health` through the intended public hostname.
2. Create the initial administrator with [local authentication](/setup/local-authentication) or [OIDC authentication](/setup/oidc-authentication).
3. Create an organization, invite users, configure a registry, and complete a [first governed scan](/setup/first-scan).
4. Add [organization policies](/organize-and-govern/policies-and-compliance), notifications, and a scoped automation token.
5. Start with a non-blocking [CI/CD integration](/integrations/ci-cd), then make the verdict required after scan, policy, and recovery behavior are understood.
6. Establish the [backup and recovery](/operate/backups-and-recovery), upgrade, monitoring, and troubleshooting routines before relying on JustScan for release decisions.
