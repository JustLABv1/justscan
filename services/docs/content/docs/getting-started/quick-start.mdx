Use Docker Compose for the shortest path to a self-hosted instance. It starts PostgreSQL, the backend, the application frontend, and this documentation service.

## Requirements

- Docker Engine with Docker Compose
- A strong PostgreSQL password
- A 32-character JWT secret and encryption key for production

## Start the stack

```sh
cd deploy/docker-compose
cp .env.example .env
# Set POSTGRES_PASSWORD in .env and review backend-config.yaml.
docker compose up -d
```

Open the address configured by `HTTP_PORT` (port `80` by default), then register the first account. The documentation is available at `/docs` on the same host.
