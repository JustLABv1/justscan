JustScan helps teams scan container images and Helm charts, investigate findings, and apply organization policy before software ships. This portal documents the current JustScan release running in your environment. Use the [release image reference](/reference/release-images) when planning an upgrade.

## Recommended rollout

1. Confirm [production readiness](/getting-started/production-readiness), select [Docker Compose](/operate/docker-compose) or [Helm](/operate/helm), and verify the service health endpoint.
2. Configure local authentication or [OIDC](/operate/authentication), then create the first organization, roles, and automation token.
3. Add and test a registry, complete a first scan, and review findings, SBOM evidence, and the policy verdict.
4. Start policy in report-only practice, set up notifications, then make the final verdict a [CI/CD gate](/integrations/ci-cd).
5. Establish the backup, upgrade, monitoring, and troubleshooting routines before relying on JustScan for release decisions.
