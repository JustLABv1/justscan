---
title: Choose a scan source
description: Select the right JustScan workflow for images, archives, Helm charts, and Git repositories.
---

| Source | Best for | Entry point |
| --- | --- | --- |
| Registry image | Images available to JustScan through a configured registry | Application or CLI |
| Local Docker/Podman image | Images that have not been pushed yet | `justscan scan --local IMAGE` |
| OCI or Docker archive | Air-gapped builds and uploaded artifacts | Application or CLI archive scan |
| Helm chart | Rendering and scanning chart workloads | Helm scan workflow |
| Git repository | Continuously discovering deployment images | Git repository discovery |

Use [image and archive scanning](/scan-and-analyze/images-and-archives), [Helm](/scan-and-analyze/helm), or [GitOps discovery](/scan-and-analyze/gitops) for detailed instructions.
