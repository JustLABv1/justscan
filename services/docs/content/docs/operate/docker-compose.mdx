---
title: Docker Compose deployment
description: Deploy JustScan, PostgreSQL, the frontend, and documentation with Docker Compose.
---

The Compose deployment routes public traffic through nginx. It exposes the application at `/`, backend API at `/api`, Swagger at `/swagger`, and documentation at `/docs`.

## Configure

Create `.env` beside `docker-compose.yml` and set `POSTGRES_PASSWORD`. It must match `database.password` in `backend-config.yaml`. For production, also replace the development-safe JWT and encryption configuration in `backend-config.yaml` with secrets delivered through your host or deployment process.

```sh
cd deploy/docker-compose
docker compose up -d
```

## Operate

```sh
docker compose logs -f
docker compose logs -f backend
docker compose pull
docker compose up -d
```

`docker compose down -v` removes PostgreSQL and backend data volumes. Back up data before using it. Verify the public hostname returns `/`, `/docs`, `/swagger`, and `/api/v1/health` after any nginx or image change.
