---
title: Helm deployment
description: Install the supported JustScan Helm chart and configure its services safely.
---

The Helm chart deploys backend, frontend, documentation, and optionally PostgreSQL. Enable ingress to expose one hostname with `/`, `/api`, `/swagger`, and `/docs` routes.

```sh
helm upgrade --install justscan oci://ghcr.io/justlabv1/charts/justscan \
  --namespace justscan --create-namespace \
  --set backend.secrets.jwtSecret="<32-or-more-characters>" \
  --set backend.secrets.encryptionKey="<32-or-more-characters>" \
  --set postgresql.auth.password="<database-password>"
```

Use a values file for production. Keep secrets in a pre-existing Kubernetes Secret when your platform manages them centrally. Set the public HTTPS URL in `backend.config.allowOrigins`, configure ingress TLS and archive upload limits, and choose a persistent storage class for PostgreSQL and any enabled backend persistence.

When `postgresql.enabled=false`, configure the external database server and provide `backend.secrets.dbPassword`. The chart creates separate backend, frontend, and documentation services; ingress exposes documentation at `/docs`.
