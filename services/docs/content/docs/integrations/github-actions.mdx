---
title: GitHub Actions
description: Scan registry, local Docker, and archive artifacts in GitHub Actions.
---

Store the organization ID and pipeline token as GitHub Actions secrets. For an image built in the runner's Docker daemon, use the CLI local-image mode so the image does not need to be pushed before scanning.

```yaml
- name: Scan image with JustScan
  env:
    JUSTSCAN_TOKEN: ${{ secrets.JUSTSCAN_TOKEN }}
  run: justscan scan --local my-app:${{ github.sha }}
```

Set the JustScan URL and organization ID in the selected CLI profile or environment. Do not print access tokens in workflow logs.
